# Dati runtime TubeTV

Questa cartella contiene lo stato generato dall'Admin e dal Bot. I file reali
non vengono pubblicati su GitHub perché possono includere account, cronologia e
configurazioni del servizio.

Per una nuova installazione copia `tubetv-data.example.json` in
`tubetv-data.json`, assegna al server PHP i permessi di scrittura sulla cartella
e poi importa o pubblica il catalogo dalla pagina Admin.
